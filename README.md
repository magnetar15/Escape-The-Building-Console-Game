# Escape from the Building

Hi! My name is Marlo. I am a student learning Python. This is my text-based adventure game, created as a project based on lessons 1–20.

## What I Have Learned

I have learned Python basics such as variables, input and output, conditions, loops, strings, lists, and dictionaries. I have also practiced functions, parameters, return values, scope, and random numbers.

## Project Task

The player is trapped inside a building with Daniel and must explore the rooms, solve riddles, discover the exit code, and escape.

### Requirements

- Present the story and the goal at the beginning.
- Let the player choose which parts of the building to explore, with at least four different rooms.
- Include at least three clues that help reveal the exit code without showing it directly.
- Include at least three riddles. Correct answers should reveal clues or unlock access to a room.
- Allow retries after a wrong riddle answer. Three wrong answers to the same riddle end the game in defeat.
- Check the final code. A wrong code uses up an attempt.
- Handle invalid choices and answers without counting them as wrong riddle answers.
- Show whether the player escaped or lost, and offer the option to play again.

## Current Game Features

- An opening story and dialogue with Daniel.
- Name entry with checks for empty, short, or invalid names.
- A menu for exploring four rooms, a hallway, and a restroom.
- A new random four-digit exit code for each game.
- Clues showing the code's digits, plus a color pattern and a reversed-word clue to help put them in order.
- Code entry with length and numeric checks, up to three attempts, and win or lose outcomes.
- Invalid menu choices are reported, and the player can start another game.

The current version focuses on exploring the building and solving the final code puzzle. The three separate interactive riddles are part of the project requirements and can be added as the game develops.
